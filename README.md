# 仿生扑翼甲斗王 · Beetle Ornithopter

基于国产甲斗王合金腰带的仿生扑翼独角仙飞行体研究原型。
目标：大四毕业前完成 V1.0 —— 扑翼飞行 + 磁吸对接 + 音效/灯效 + AI 语音交互。
