# 甲斗王智能扑翼 · 学习路线周计划（大一上 → 大四下）

> 目标：大四毕业前交付 **V1.0 可展示研究原型**（仿生扑翼独角仙 + 磁吸对接 + 音效/灯效 + AI 语音）
> 创建：2026-10-07；修订 v2：2026-10-07（加入 10-10~10-26 军训；确认已有 VS Code/GitHub、部分 Java 基础）
> 当前进度：**大一上 第 6 周**（今天 2026-10-07）；10-08/09 是军训前最后两天自由时间；10-10（周六）~ 10-26（周一）军训
> 用法：每周日对照本表回顾 30 分钟，把进展写进 GitHub 仓库 `logs/`；每学期末滚动修订后续学期。

## 0. 使用原则（每周都适用）

1. **软件先行、仿真先行**：代码不花钱，先跑通再买硬件。
2. **单翅测试台是核心**：全部测量数据从它出，比“外形像不像”重要。
3. **GPA 与考研优先**：项目为复试/简历服务，不为它牺牲成绩。
4. **安全红线**：宿舍只做无桨测试；装桨去室外；锂电池用防爆袋；电烙铁等导员批准后用。
5. **分级目标**：每个阶段都有底线/基准/冲刺。落后时砍冲刺保底线，不砍考研和 GPA。

- 扑翼做不出：退到共轴双桨/涵道版，测试台数据 + 控制代码照样支撑毕设。
- 考研压力：大三下起项目冻结为每周半天；毕设只用已有素材。
- 预算超支：优先第 1、3 期；第 6 期可砍（用 AprilTag/手机方案替代 UWB）。
- 安全：宿舍无桨、室外装桨、电池防爆袋、同伴在场。
